Privacy policy

PersonalAssistant (mail triage) — last updated 15 October 2026

Who operates this application

Tom Pijls, as a private individual, for his own mailbox. Contact: tom.pijls@gmail.com.

Who uses it

Only the operator's own Google account. No other users can sign in.

What Google data is accessed

Gmail messages in the operator's mailbox are read to sort them, and labels are added or the message is moved out of the inbox (the gmail.modify OAuth scope). Messages are never deleted or sent. One Google Sheet created by the app itself holds a list of senders (the drive.file OAuth scope); no other Drive files are accessed.

Processing and sharing

Processing happens on a server operated by Tom Pijls. Sender, subject and the start of the message body are sent to Anthropic's Claude API to classify the message. Nothing else is shared, sold or used for advertising.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data

Access can be revoked at any time from the Google account's third-party access settings. Stored state and tokens are deleted by the operator on request.
